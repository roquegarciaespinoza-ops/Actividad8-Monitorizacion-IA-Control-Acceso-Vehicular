# Fuentes y alcance

Actividad 8, módulo 3, semana 10, gestión de proyectos de inteligencia artificial.

## Fuentes
- Consigna e instrucciones de Actividad 8 entregadas por el estudiante.
- Rúbrica oficial: cuatro criterios de 25 puntos.
- Tema 19: Monitorización proactiva y alertas en tiempo real.
- Tema 20: Mantenimiento, respuesta a incidentes y gobernanza operativa.

## Delimitación
Este repositorio es independiente y toma como caso de uso un sistema de IA para control de acceso vehicular de residentes. Los anteriores repositorios se utilizarán únicamente como fuentes de consulta hasta seleccionar la versión a integrar. Todo indicador definido aquí es propuesto, no medido. Todo resultado sintético debe identificarse expresamente. No accionar hardware físico ni utilizar datos reales de residentes en pruebas.
