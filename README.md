# Actividad 8 — Monitorización de IA para control de acceso vehicular

Proyecto académico de Gestión de proyectos de inteligencia artificial, Módulo 3, Semana 10 (temas 19 y 20).

## Propósito
Diseñar e implementar observabilidad, alertas inteligentes basadas en SLO y error budgets, simulaciones de incidentes con runbooks y documentación de respuesta automatizada para un sistema de control de acceso vehicular de residentes.

**Estado:** estructura inicial y diseño documental; instrumentación, capturas y simulaciones aún pendientes.

## Criterios de evaluación
| Criterio | Peso |
|---|---:|
| Métricas, logs, trazas y objetivos de operación | 25 |
| Alertas inteligentes, SLO, error budgets y reducción de ruido | 25 |
| Incidentes simulados y runbooks ejecutados | 25 |
| Documentación y respuesta automatizada efectiva | 25 |

Seguimiento detallado: [Matriz de rúbrica](docs/07_matriz_rubrica.md).

## Seguridad y ética
Todo acceso y actuador se simulará; no se manipularán barreras físicas ni se subirán matrículas, imágenes personales o credenciales. Ante error o incertidumbre, no autorizar automáticamente el acceso.

## Entrega final
Preparar documento técnico, evidencia de implementación, simulación de incidentes y código/configuración, empaquetados en un ZIP. Los resultados se documentarán solo después de ejecutarse.
